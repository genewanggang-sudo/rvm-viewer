### 遇到的问题与解决

线上旧包把 Worker 写为根目录 `/rvmsdk/`；源码已改用 Vite BASE_URL 并重新构建。
平台生成页有时不注入 base，导致 `media/...` 被误解析为配置页路径。
天赋薄页现通过嵌套 srcdoc 启动部署入口，注入部署目录 Worker 地址与文件查询参数；
缺少 base 时从父页面智能体 ID 推导平台工作区文件接口。真实对话已验证该兼容路径。

### 本轮真实发现的问题

普通聊天 URL 为 `/aidt/chat?agent_id=cr36T4&chat_id=...`，平台同样没有注入 base。
旧 v3 只读取配置页路径，错误请求 `/aidt/media/...`，收到的不是 RVM 文件，导致解析失败。
此问题在配置页测试中未覆盖，不能用第一轮验收宣称普通聊天已成功。

源码已兼容聊天的 `agent_id` 查询参数，保持智能体 ID 和技能名不变。
平台普通 PUT 或覆盖挂载接口即使返回成功，也未替换实际脚本。
最终用平台编辑器的 ZIP 替换流程更新技能池，再解除当前技能挂载并重新安装，
运行时脚本、技能池脚本和本地发布包逐字相同。旧运行时内容已备份至
`tmp/aidt-release/2026-09-17-v3-chat-entry/platform-before.json`，可恢复。
