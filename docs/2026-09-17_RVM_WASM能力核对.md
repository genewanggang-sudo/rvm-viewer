# RVM WASM 能力核对

- 依据：随前端部署的 `public/rvmsdk/rvm-sdk.d.ts`、`rvm-worker.js` 与 SDK API 文档
- 产品决策：查看器仅暴露单 `.rvm` 输入

## 已确认能力

WASM 在 Worker 内接收 `open(name, bytes, attrs?)`。单个 RVM 的 `bytes` 已能打开场景，
`preview(handle)` 返回 three.js 可加载的 GLB。`open` 和 `preview` 是长任务，RPC 默认
超时 180 秒，因此解析不会阻塞浏览器主线程。

底层按扩展名还实现了 `rvmtxt`、OBJ、GLB、glTF、STL、PLY、ZIP 等格式，以及 12 种
导出格式。这是 SDK 能力，不是本产品的输入承诺；前端通道、本地选择器、AIDT 天赋和
交付文档均只允许 `.rvm`。

## CADC TXT 的边界

`attrs` 可传入 RVM 配套的 CADC `.txt`。WASM 会按节点名挂接属性，可用
`tree(handle)` 取得节点 `segments`，再用 `getProperties(handle, segments)` 读取
`[{ name, value }]`。实际样本 `WD1-PSUP.RVM + WD1-PSUP.txt` 识别出 4,084 个属性节点，
可读取 `rvm:RefNo`、`rvm:Type`、`rvm:Position` 等键。

当前查看器的目标是快速几何预览：只传 RVM，并在生成 GLB 后释放 WASM 场景句柄。因此
不会出现属性树或 TXT 选择控件。未来若需要构件数据，必须把范围升级为“一个必选 RVM +
一个可选 TXT”，保留句柄并新增树/属性面板；浏览器不能自动读取用户选择 RVM 同目录的
TXT 文件。
