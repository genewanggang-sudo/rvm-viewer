# 前端 React 工程架构

- 日期：2026-09-17
- 状态：已实施

```text
protocol.ts / dataChannels.ts
  -> useViewer.ts
  -> rvmSdk.ts + ViewerEngine.ts
  -> App.tsx + UI components
```

- `dataChannels.ts` 只接受 `?file=` 指向的 RVM 文件。
- `useViewer.ts` 管理本地/平台/测试文件加载、UI 状态和渲染完成回执。
- `rvmSdk.ts` 用 Worker RPC 调用 WASM 的 `open` 与 `preview`，并把 GLB 预览交给 three.js。
- `ViewerEngine.ts` 管理画布、资源释放、OrbitControls、自动取景和相机复位。
- `components/` 只负责加载面板、状态、模型统计和相机按钮，不承担文件协议或 WebGL 生命周期。

相机在每次模型加载后按包围球自动适配；“适配模型”保留当前观察方向，“恢复等轴视图”
回到确定的工业查看初始视角。生产嵌入模式隐藏本地控件，避免 AIDT iframe 中出现无效的
本地测试入口。

`pnpm verify` 是完整质量门禁：格式、lint、严格 TypeScript、100% 类型覆盖、Vitest 覆盖
和 Vite 生产构建。所有一次性模型、浏览器 profile、截图和发布产物都在根 `tmp/`。
