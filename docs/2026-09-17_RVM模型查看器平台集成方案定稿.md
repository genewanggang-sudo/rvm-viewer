# RVM 模型查看器平台集成方案

- 日期：2026-09-17
- 状态：本地构建和交付包已准备，等待真实 AIDT HTTPS 部署验收
- 范围：单 RVM 文件的聊天预览和外部静态查看器

## 交付链路

```text
用户上传 .rvm
  -> AIDT 工作区 media/<uuid>_model.rvm
  -> pack_thin_html.mjs 生成薄 HTML
  -> 聊天预览以 srcdoc 打开薄 HTML
  -> 薄 HTML 将 media 路径解析为绝对文件 URL
  -> HTTPS viewer 的 iframe 读取 URL，Worker/WASM 解析并渲染
  -> viewer 发送 rvm-viewer:rendered 回执，薄页显示成功状态
```

薄 HTML 必须在自身的 `document.baseURI` 中解析文件引用，不能让外部 viewer 以自身
静态站域名解析 `media/...`。iframe URL 固定增加 `embed=1`，因此平台中只显示模型画布，
加载状态由外层薄页呈现。

## 发布步骤

1. 部署 `frontend/dist/` 到固定 HTTPS 根地址，并验证 `.wasm` 的 MIME 类型。
2. 执行 `corepack pnpm@10.12.1 prepare:aidt -- --viewer-url <HTTPS URL>`。
3. 上传发布目录的 `viewer/`，压缩同目录 `agent/` 并上传到 AIDT。
4. 在真实聊天中上传一个 RVM，生成并打开薄 HTML。
5. 记录 viewer 中 RVM 请求的 URL、状态码、响应头及 CORS/Cookie 错误（若有）。

## 验收边界

本地可验证 WASM 解析、相机、回执和静态构建；真实 AIDT 尚取决于平台文件服务是否允许
HTTPS viewer 在 iframe 中携带登录态读取该绝对 URL。未提供真实 HTTPS 地址和平台会话前，
该项只能标为待验收，不能声称平台 E2E 已完成。
